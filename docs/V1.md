# v1 scope and verification

v1 is a small administrator-provisioned social blog, usable locally and packaged
for the existing publishing foundation. Public launch is separate from the v1
implementation. Do not add features to this project while the other selected
projects still need their v1 work.

- [x] Separate member sessions, safe password storage, logout and expiry.
- [x] Publish, reply, edit/delete own content, stale-edit protection.
- [x] Profile display, following and a chronological following feed.
- [x] Post/member search and bounded cursor pagination.
- [x] Personal hide/unhide, report submission, moderator queue and decisions.
- [x] Removed/deleted placeholders preserve existing conversation structure.
- [x] Separate moderator role; administrative account creation on stdin.
- [x] Repeatable local setup that preserves content and credentials.
- [x] App-local design tokens, responsive layouts, keyboard focus.
- [x] PostgreSQL integration tests and browser workflows.
- [x] Readme and case study grounded in observed behavior.
- [x] Container build and isolated read-only runtime check, including provisioning.

The [disposable deployment](DEPLOYMENT.md) passed real HTTPS member workflows,
automatic startup after reboot, and independent workstation database recovery.
GitHub publication, actual domain, public preview, independent review and
automated off-server backup delivery remain launch work, not additional product
features. The test deployment does not establish production availability.

Deferred: open registration, profile editing, password reset, rich media, nested
reply trees, likes/reposts, notifications, ranking, external identity providers,
and moderation automation. No commitment to these features is implied by v1.
